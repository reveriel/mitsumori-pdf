見積書と請求書の役割の違い

見積書は、「この作業を、この内容で、この金額でお受けします」という申込みの意思表示を書面にしたものです。 発注者はこの金額を見て、発注するかどうか、予算に合うかを検討します。この時点ではまだ契約は成立しておらず、 発注者が内容を承諾して注文書を出すなどして、はじめて契約に進みます。

一方の請求書は、「約束した作業が完了したので、代金をお支払いください」という支払いの請求です。 すでに発生した売買や役務の対価を確定させて支払いを求める書類であり、見積書のように「検討してもらう」ためのものではありません。 同じ金額を書いていても、相手に求める行動がまったく違う、という点が両者の本質的な違いです。

一目でわかる比較表

まずは、見積書と請求書の違いを項目ごとに整理します。

比較項目見積書請求書
目的 発注前に金額・条件を提示し、検討してもらう 納品後に代金の支払いを請求する
発行タイミング 受注・契約の前 納品・作業完了の後
発行する人 受注する側（売り手・受託者） 代金を受け取る側（売り手・受託者）
法的な性質 申込みの意思表示。発行だけでは契約は成立せず、拘束力は原則なし 既に成立した契約に基づく支払請求。金額は確定している
金額の状態 未確定の見込み額。変更されうる 確定した請求額

印紙税 原則として課税文書にあたらず、収入印紙は不要とされる 請求書も課税文書ではなく、通常は収入印紙は不要
書き換え 条件が変われば再発行できる 訂正する場合は訂正後の請求書を再発行する

発行タイミングの違い

実務の流れを追うと、両者のタイミングの違いがはっきりします。一般的な取引は、 「見積書 → 注文書 → 納品書 → 請求書」の順に進みます。

  1. 見積書 — 受注する側が、まだ契約前の段階で金額と条件を提示します。
  2. 注文書 — 発注者が内容を承諾し、発注の意思を書面で示します。ここで契約が成立することが多いです。
  3. 納品書 — 作業や物品の受け渡しが完了したことを示します。
  4. 請求書 — 納品を確認したうえで、代金の支払いを請求します。

この流れのどこかが抜けると、後から「言った・言わない」のトラブルになりやすくなります。 とくに、見積書を出さずに口頭で金額を決めてしまうと、後から追加作業が発生したときの線引きが曖昧になります。 逆に、請求書を納品前に出してしまうと、検収前の支払いを求める形になり、取引先の経理処理と噛み合わないことがあります。

法的拘束力の違い

見積書は申込みの意思表示であり、発行しただけでは契約は成立していません。 したがって、見積書の金額や条件は、双方の合意が得られる前であれば変更すること自体は可能です。 ただし、発注者が見積内容を承諾して注文書を出した場合は、その内容が契約条件として扱われることがあるため、 承諾後の一方的な変更は避けるべきです。

一方、請求書はすでに成立した契約に基づく支払請求です。契約と納品が済んでいる以上、 請求額は確定しており、売り手が一方的に増額したり減額したりできる性質のものではありません。 「見積書はお願いの書類」「請求書は確定した請求の書類」と覚えておくと、判断を誤りにくくなります。

記載項目の違い

両者に共通する項目も多いですが、役割の違いから、求められる記載は次のように異なります。

見積書に特徴的な項目

  • 見積の有効期限 — 材料費や工数の変動を踏まえ、いつまでの金額かを示します。
  • 見積条件・除外範囲 — 「本見積に含まれない作業は別途見積とする」旨を明記します。
  • 見積番号 — 後の注文書・請求書との突き合わせに使います。

請求書に特徴的な項目

  • 請求書番号と請求日 — 入金管理の単位になります。
  • 支払期限と振込先 — いつまでに、どの口座へ支払うかを示します。
  • 登録番号・適用税率・消費税額 — インボイス制度に対応するための記載です。

逆に、宛名と敬称（法人は「御中」、個人は「様」）、発行元の情報、明細（品名・数量・単価・金額）、 小計・消費税・合計といった項目は、どちらの書類にも共通して必要です。 見積書の記載項目を一つずつ確認したい場合は、 見積書の書き方と記載項目ガイドで詳しく解説しています。

税務上の違い（消費税・インボイス・印紙税）

消費税の税率は、見積書でも請求書でも原則10%（標準税率）、一定の取引には 8%（軽減税率）が適用される点は同じです。税抜金額・消費税額・税込合計を分けて示す書き方も共通しています。

大きく違うのはインボイス制度への対応です。 見積書はインボイス制度上の適格請求書にはあたらず、登録番号の記載は必須ではありません。 一方、実際に代金を請求する段階では、登録番号・適用税率・消費税額などを記載した 適格請求書（または適格簡易請求書）を交付する義務があります。 したがって、見積書を作っただけで請求が済んだことにはならず、請求の段階で改めて適格請求書を発行する必要があります。

印紙税については、見積書・請求書のいずれも、それ自体が課税対象となる文書（課税文書）にはあたらないとされるのが一般的で、 通常は収入印紙は不要です。ただし、見積書に契約内容そのものを記載し、双方が署名・捺印して契約書として扱う場合などは、 課税文書に該当し印紙税がかかることがあります。

補足：消費税やインボイス、印紙税の個別の判断は、取引の実態によって変わります。 本記事の内容は一般的な情報であり、個別の税務判断を保証するものではありません。判断に迷う場合は税務署や税理士にご確認ください。

使い分けの実務ポイント

見積書と請求書を正しく使い分けるために、次の点を押さえておきましょう。

  • 見積書なしで作業を始めない — 金額の根拠を書面に残しておくと、後の追加作業も説明しやすくなります。
  • 見積番号と請求番号を関連付ける — 同じ取引の書類がつながり、入金確認が楽になります。
  • 金額を変えるときは再見積もり — 追加や仕様変更があれば、止めずに新しい見積書を発行して承諾を得ます。
  • 請求は納品のあとに — 検収前の請求は経理処理と噛み合わず、入金が遅れる原因になります。
  • 請求時はインボイスの要件を満たす — 登録番号や適用税率の記載を忘れないようにします。

よくある間違い

  • 見積書の金額をそのまま請求書に流用する — 追加作業があれば金額は変わります。見積額と請求額を機械的に同じにすると、実態とずれます。
  • 見積書に有効期限を入れない — 値上がり後も同じ金額での対応を求められることがあります。
  • 請求書に「見積書のとおり」とだけ書く — 何に対する請求かが分からず、取引先の経理で止まりやすくなります。
  • 見積書をインボイスの代わりにする — 見積書は適格請求書ではないため、交付義務を満たしません。

よくある質問

見積書と請求書はどちらを先に発行しますか？
見積書が先です。見積書は発注の前に金額や条件を提示する書類で、発注者がそれを承諾して発注すると契約に進みます。請求書は、作業が完了して納品が済んだあとに、実際に発生した代金を請求する書類です。したがって一般的な流れは「見積書 → 注文書 → 納品書 → 請求書」の順になります。
見積書に法的拘束力はありますか？
見積書は「この金額でお受けします」という申込みの意思表示であり、発行しただけでは契約は成立しておらず、法的拘束力は原則として生じません。ただし、発注者が見積内容を承諾して注文書を出すなど双方の合意が成立すれば、その内容が契約条件になることがあります。見積書の段階でも、有効期限を明示すると後の行き違いを防げます。
見積書の金額と請求書の金額が違ってもよいですか？
追加作業や仕様変更がなければ、一致させるのが基本です。金額が変わる場合は、追加分の見積書をあらためて発行し、発注者の承諾を得たうえで請求するのが安全です。根拠を示さずに請求額だけが増えていると、支払いが遅れたり信頼を損ねたりする原因になります。
見積書もインボイス（適格請求書）として扱えますか？
見積書はインボイス制度上の適格請求書ではありません。実際に代金を請求する段階では、登録番号や適用税率、消費税額などを記載した適格請求書（または適格簡易請求書）を別途発行する必要があります。見積書に登録番号を載せること自体は任意ですが、それだけでは交付義務を満たしません。
