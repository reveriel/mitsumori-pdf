プライバシーポリシー

制定日：2026年10月12日

本プライバシーポリシー（以下「本ポリシー」といいます）は、当方が提供する「見積書 PDF 生成ツール」（以下「本サービス」といいます）における、 利用者の情報の取扱い方針を定めるものです。

1. 本サービスの基本方針

本サービスは、お使いのブラウザ内だけで動作する純粋なウェブツールです。 見積書の作成のために入力していただいた自社名・宛名・住所・電話番号・メールアドレス・明細・金額などの内容は、 当方のサーバーへ送信されることはなく、当方が保存・収集することもありません。

入力内容はお使いの端末のブラウザ内メモリ上でのみ処理され、ページを閉じたり再読み込みしたりすると破棄されます。 当方が入力内容を閲覧・取得することは技術的に不可能です。

2. 取得する情報

本サービスにおいて当方が取り扱う情報は、次のものに限られます。

  • アクセス解析情報 — ページの閲覧状況を把握するための、匿名化された統計情報（後述）。
  • お問い合わせ・フィードバックの内容 — 利用者ご自身が任意で送信された内容（後述）。

本サービスは、見積書作成のための入力内容そのものを取得することはありません。

3. アクセス解析について（Cloudflare Web Analytics）

本サービスでは、サイトの利用状況を把握し改善するために、Cloudflare, Inc. が提供する「Cloudflare Web Analytics」を利用しています。 同サービスは Cookie を使用せず、個人を特定する情報を収集しない、プライバシー重視の設計となっています。

同サービスの計測のために、利用者のブラウザから Cloudflare の配信サーバーへ通信が発生し、 ページビュー数・参照元・閲覧したページ・ブラウザや OS の種類・国・おおよその地域などの統計的な技術情報が記録されることがあります。 これらは匿名の集計データとして扱われ、個人を識別する目的では利用しません。

Cloudflare Web Analytics の詳細および同社のデータ取扱いについては、Cloudflare 社のプライバシーポリシーをご確認ください。

4. お問い合わせ・フィードバックについて（Google フォーム）

本サービスでは、ご意見・ご要望・不具合のご報告を受け付けるために、 Google LLC が提供する「Google フォーム」を利用したフィードバックフォームを設置しています。

フォームは利用者が任意で送信するもので、送信された内容（ご意見の本文、および利用者が任意で入力した連絡先など）は、 当方が今後の改善のために利用します。フォームの送信内容は Google のサービス上に保存され、同社のプライバシーポリシーが適用されます。

フォームのご利用は任意です。送信しなくても本サービスの機能はすべてご利用いただけます。 なお、フォームに見積書の入力内容や取引先の個人情報など、機密性の高い情報を記載しないでください。

5. 個人情報の第三者提供

当方は、上記の解析・フォームの各サービス提供者を除き、取得した情報を第三者へ提供することはありません。 ただし、次のいずれかに該当する場合はこの限りではありません。

  1. 利用者ご本人の同意がある場合
  2. 法令に基づき開示が求められた場合
  3. 人の生命、身体または財産の保護のために必要があり、ご本人の同意を得ることが困難な場合

6. 安全管理

本サービスは HTTPS（TLS）による通信の暗号化に対応しています。 また、そもそも入力内容をサーバーへ送信しない設計とすることで、 見積書に関する情報が外部へ漏えいするリスクを最小化しています。

7. Cookie・ブラウザ保存領域の利用

本サービス自体は、入力内容を保存するための Cookie や localStorage を利用していません。 アクセス解析に用いる Cloudflare Web Analytics も Cookie を使用しません。 Google フォームのページへ移動した場合は、同サービスの Cookie が利用されることがあります。

8. 本ポリシーの変更

当方は、法令の変更やサービス内容の変更に応じて、本ポリシーを変更することがあります。 変更後の本ポリシーは、本ページに掲示した時点から効力を生じるものとします。
